# Solutions

**Not on the main branch until the labs.** Keep this folder on the `solutions` branch. The solutions of each lab are shown at the beginning of the next lab: merge them then.

- `lab1/` … `lab4/`: solution notebooks of the course exercises.
- The original C++ macros of the earlier editions are in [`gallery/solutions/<case>/`](../../gallery/solutions/), grouped by use-case.
  `not-yet-documented-cases/` holds material (ARIADNE, moon shadow, unfolding) that has no use-case file yet; `misc-exercises/` holds macros not matched to a case.

Notebook paths (`../../../gallery/...`) are valid from `course/solutions/labN/`.
